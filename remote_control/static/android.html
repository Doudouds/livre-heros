APPLICATION ANDROID · VERSION 1.1.0

Une porte dans votre poche.

L’application Android donne accès à la bibliothèque, aux commandes audio et aux choix des histoires. Le son est joué par le lecteur connecté.

Télécharger l’APK Android →

Ouvrez le fichier téléchargé pour l’installer. Si Android le demande, autorisez cette installation depuis votre navigateur.

Dans l’application, saisissez l’adresse de ce lecteur et le code à huit chiffres affiché sur le PC. Gardez le lecteur lancé et les deux appareils sur le même Wi-Fi.

Android 8 ou plus récent. Application de test installée directement, sans compte ni magasin d’applications. Si le fichier est absent, lancer Compiler_Application_Android.cmd sur le PC.
